# 大團系統 PRD

> 狀態：討論中。本文件只記錄已確認的結論，尚未定案的項目列在「待決事項」。

## 1. 產品概述

團體行程報名 SaaS。企業可建立活動並產生報名前台，企業會員可在前台瀏覽行程資訊、選擇報名人數、填寫旅客資料並完成報名。後台可建立活動、設定自選行程，以及自訂旅客資料欄位。

## 2. 角色與權限

### 2.1 後台角色

| 角色 | 身分 | 職責 |
|---|---|---|
| 平台人員 | 平台經營者 | 經營平台，開通平台權限給旅行社 |
| 旅行社人員 | 旅行社的平台操作人員 | 建立基本報名資料與報名網頁相關設定，報名網頁提供給企業員工使用 |
| 企業窗口 | 企業方窗口 | 設定可操作報名網頁的企業員工資料 |

### 2.2 租戶模型

- 平台的客戶是旅行社，平台會服務多間旅行社。
- 每間旅行社是獨立租戶，彼此的資料與權限完全分開、沒有關聯。

### 2.3 前台角色

| 角色 | 職責 |
|---|---|
| 企業員工 | 瀏覽行程、選擇報名人數、填寫旅客資料、完成報名 |

## 3. 待決事項

- [ ] 企業窗口除員工資料外，是否還有其他後台權限
- [ ] 付款：完成報名是否包含線上付款
- [ ] 員工身分：員工資料的欄位、匯入方式與前台驗證方式
- [ ] 名額控管：名額設定層級與額滿處理
- [ ] 自選行程：形式與計算單位
- [ ] 報名後異動：修改與取消規則
- [ ] 成行後作業：分房、分車、保險名單與資料匯出的範圍
- [ ] 個資：收集項目與保護要求
