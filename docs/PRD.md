# 大團系統 PRD

> 狀態：討論中。本文件只記錄已確認的結論，尚未定案的項目列在「待決事項」。

## 1. 產品概述

團體行程報名 SaaS。企業可建立活動並產生報名前台，企業會員可在前台瀏覽行程資訊、選擇報名人數、填寫旅客資料並完成報名。後台可建立活動、設定自選行程，以及自訂旅客資料欄位。

## 2. 角色與權限

### 2.1 後台角色

| 角色 | 職責 |
|---|---|
| 平台人員 | 負責開平台 |
| 旅行社人員 | 負責開專案給企業 |
| 企業窗口 | 希望可自助操作後台（權限範圍待定） |

### 2.2 前台角色

| 角色 | 職責 |
|---|---|
| 企業會員 | 瀏覽行程、選擇報名人數、填寫旅客資料、完成報名 |

## 3. 待決事項

- [ ] 「開平台」的具體內容，以及旅行社是否為獨立租戶
- [ ] 旅行社人員與企業窗口在專案、活動上的權限分工
- [ ] 付款：完成報名是否包含線上付款
- [ ] 會員身分：如何確認報名者屬於該企業
- [ ] 名額控管：名額設定層級與額滿處理
- [ ] 自選行程：形式與計算單位
- [ ] 報名後異動：修改與取消規則
- [ ] 成行後作業：分房、分車、保險名單與資料匯出的範圍
- [ ] 個資：收集項目與保護要求
